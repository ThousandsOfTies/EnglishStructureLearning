# レベル2：助動詞・否定・頻度・144文

日本語のカードを、できあがる英文の順に並べます。

「元の文」がある例の多くは、レベル1の場面から組み合わせごとに10文ずつ自動で作りました。これらにはまだ絵がありません。

can・might・must・should のグループから始め、そのあとで「ふだん・過去・今・状態・経験」の否定と、頻度を練習します。

助動詞は、場面に合う日本語に、その助動詞に共通する意味を括弧で添えます。

## できる・かもしれない・必要・おすすめ
