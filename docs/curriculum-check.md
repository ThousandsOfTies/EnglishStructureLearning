# 文章の点検と実機での確認メモ

## レベル1の派生文

基本の場面を起点に、進行形・過去形で動詞のつづりや日本語の語尾、人物・数・時間が合っているかを点検しました。

| 確認した点 | 修正例 |
| --- | --- |
| 英語の進行形のつづり | `cuting` を `cutting` に修正。りんご・紙・パンの3場面に反映 |
| 日本語の進行形 | 「やってみています」を「試しています」、「しまっておいています」を「しまっています」に変更 |
| 服と人物の人数 | 複数の子が着るシャツ・コートは複数形にし、一人が着がえる上着は単数形に変更。靴下は「はきかえる」と表現 |
| 出来事と頻度 | 毎日の誕生日会への招待は「年に一度」に、チームやクラブへの加入は「新学期に」に変更。「昨日、生徒でした」は「去年、生徒でした」に変更 |
| 練習中の表記 | つづりを答える問題の `cat` などを「『ねこ』を表す英単語」のような日本語に変更。自分を描く問題は「自分を絵にかく」と明示 |

「友だちに毎日名前をたずねる」は、毎日同じ相手に聞いているようにも取れるため、「登校初日に新しいクラスメートに名前をたずねる」に変更しました。絵や話の流れで無理がある例は、実機確認で問題IDを控えます。

## 実機・お子さんでの確認

| 見るもの | 確認すること |
| --- | --- |
| レベル1の「おにぎりを食べている」 | ヘルプを見たあとで、助述部に「である」、述語に「食べている」を選べるか。「いる」が二重に見えて止まるか |
| レベル2の「紙のぼうしを作れる」と「紙のぼうしを作るかもしれない」 | ヒントを読む前に、親指を上げる顔と、汗をかいて迷う顔から別の意味を思い浮かべるか。自転車など場面を変えても同じように読めるか |
| レベル2の can と should | 親指を上げて自信を伝えるしぐさと、手のひらを出して勧めるしぐさを見分けられるか |
| スマホの「時制の絵くらべ」 | 同じ動作の現在進行形と現在完了（経験）を並べて、右端の最も淡く短い線まで拡大せずに数えられるか。線の見え方から２つを区別できるか |
| レベル3の Why と How | 字のヒントを読む前に、Why の「何が起きたの？」と How の「どうやって作ったの？」を区別できるか |
| 自動生成したレベル2・3（絵なし） | 「〜しなかった」で did のあとの述語を eat の形に戻せるか。What does he…? で does と述語の形を選べるか。Who が主語の文で助述部を前に出さずに並べられるか |
| レベル3の「空席」 | Can you always be happy? で、前へ出るのは can だけで、「いつも」と be は空席のところに残ると分かるか。空席にカードを置こうとして迷わないか |

見えにくい場合は、問題ID、端末と向き、子どもが最初に言ったこと、選んだ欄を残します。

## 作画が必要な追加候補

| 対象 | 追加したい問題 |
| --- | --- |
| Why の目的 | 今の Why はすべて「［？］→ 結果」の原因型。「行動 →［？］」の目的型を1問以上加え、Why＝手前の箱だけ、と覚えないようにする |
| How の一般化 | 今の How は「材料 → 完成品」の2問だけ。`How do you go to school?` のように作る場面以外でも、両端を見せて途中をぐるぐる線＋「？」にする構図が通じるか確かめる |
| 否定疑問 | `Don't you…?` などは一度外した。助述部の考え方がいちばん生きる形なので、レベル3の後半に戻す候補として残す |
| 道具・手段 | 「この紙で」のような道具は、今の欄（対象・場所・時）に入らないため例文から外した。道具の欄を作るかは今後検討する |
