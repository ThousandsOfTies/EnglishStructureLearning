# ことばのならべかた

index.html をブラウザーで開くと使えます。通常版は assets フォルダーも一緒にコピーしてください。画像を埋め込んだ1ファイル版も作成できます。全10章・640例文に対応しています。

1. 日本語のカードをS・V・O/P・Mのエリアへドラッグします。カード→エリアの順にタップしても移動できます。最後に「たしかめる」。
2. 正解したら「絵からつくるへ」。横一列のS・V・O/P・Mのドロップダウンから日本語を選び、「たしかめる」を押します。Mも判定対象です。
3. 正解すると、S・V・O/P・Mそれぞれの選択欄の真下に、対応する英語を表示します。「英語を聞く」はブラウザーの音声合成を使います。
4. 「音声設定」でポップアップを開き、端末で使える英語音声を選べます。「試しに聞く」で確かめ、「保存する」を押すと次回も同じ声を使います。声の種類は端末・ブラウザーによって異なり、英語音声の追加が必要な場合もあります。

進み具合は同じブラウザーの保存領域に記録されます。ブラウザーやファイルの場所を変えると引き継がれない場合があります。保存機能が使えなくても練習できます。

O/Pは「何を・どこへ・だれに」をまとめる教材用の箱です。直接の目的語か、前置詞でつなぐ部分かは、ここでは区別しません。Mには時間・方法・目的・同行者などをまとめます。正式な五文型の分類ではなく、子供が英語の大きな枠組みをつかむための練習です。

長い目的の部分など、入れ子の構造はまとめて扱う入門用の教材です。選択肢は元の10例文に対応します。画像だけでは時制・地名・人物関係は確定できないため、手がかり文を併用します。

エリアはS→V→O/P→Mの順に開きます（その文で使わない役割は飛ばします）。正誤に関係なく、現在のエリアに1枚置くと次が開きます。一度開いたエリアは有効なままです。「この文のマークを消す」で順序も最初に戻ります。命令形では隠れたSを選ぶとVが開きます。

S・V・O/P・Mのエリアは画面幅にかかわらず横一列です。入りきらない場合はエリアを左右にスクロールできます。

章の選択と章内検索で例文を探せます。絵にしにくい抽象的な文は理由を示し、日本語から組み立てる練習にします。

疑問文・縮約形・複数の節では、役割の箱と実際に書く語順が異なるため、正確な英文も併記します。日本語と英語で主語や表現が変わる例は、1段階目で自然な日本語の役割を見つけ、2段階目で英語の形に合う日本語を選びます。案内が出るので、必要に応じて大人向けの説明も確認してください。
